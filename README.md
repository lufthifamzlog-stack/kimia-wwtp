# Logbook Kimia WWTP

Aplikasi pencatatan keluar-masuk bahan kimia untuk WWTP / IPAL: stok, pemakaian per titik dosing, opname, rekap bulanan, dan peringatan stok minimum.

- `web/` — aplikasinya (website/PWA, bisa jalan offline)
- `android/` — pembungkus Android (APK)
- `.github/workflows/build.yml` — otomatis membuat APK + website gratis di GitHub
- `firestore.rules` — aturan keamanan untuk sinkron tim (opsional)

Langkah lengkap ada di **PANDUAN.md**.
